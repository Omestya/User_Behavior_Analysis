# User_Behavior_Analysis
 Conducted user cohort analysis and calculated retention rates. Analyzed user retention trends over  time and compared the performance of different acquisition channels (Promo vs. Organic). 
 [Link to the Google Sheets spreadsheet](https://docs.google.com/spreadsheets/d/1RqwkBRaL1lF3vwCTbQp7m5fQdv-y3Rfj1uyM_7F1g9E/edit?usp=sharing)
# The following tasks have been completed in the .sql file.
 - Created CTEs to clean dates in `cohort_users_raw` and `cohort_events_raw` (used `CASE` to check the format).
 - Joined the cleaned tables.
 - Applied the necessary data filtering.
 - Constructed the final aggregated table.
